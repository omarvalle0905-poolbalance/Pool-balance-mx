## ✅ Pasos para cambiar una foto

1. **Descarga o crea** la foto nueva (horizontal, mínimo 1400×900 px)
2. **Ponle el nombre exacto** de la tabla de arriba (respeta mayúsculas y extensión)
3. **Súbela** a esta carpeta `images/`
4. **Confirma** que reemplazó el archivo anterior cuando te pregunte
5. **¡Listo!** La app se actualiza automáticamente — sin tocar código

---

## 🎨 Tips para que se vean bien

- Las fotos se muestran **de pantalla completa** como fondo del hero
- El texto blanco queda encima — **evita fondos muy claros o muy blancos**
- **Las mejores fotos** tienen agua azul profundo, luz natural, contraste alto
- Si Yamile genera las imágenes con IA, dile que use formato **horizontal 16:9**
  y fondo oscuro/azulado para que el texto blanco se lea bien encima

## 🔊 Audios opcionales (cuando los tengas)

Los audios también tienen nombres fijos. Guárdalos en la carpeta `audios/`:

| Audio | Nombre exacto |
|-------|--------------|
| Slide 1 | `carousel-1.mp3` |
| Slide 2 | `carousel-2.mp3` |
| Slide 3 | `carousel-3.mp3` |
| Slide 4 | `carousel-4.mp3` |

Para activarlos, abre `data/config.js` y busca la línea:
```
// audio: "audios/carousel-1.mp3",
```
Quita el `//` del inicio de esa línea. Eso es todo.
