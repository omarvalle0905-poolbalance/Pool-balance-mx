# Brief Creativo

Usa esta referencia cuando Omar pide un brief de campaña completo (más amplio que una sola pieza) — por ejemplo, el lanzamiento de un servicio nuevo, una serie de contenido, o una campaña estacional.

Resuelve primero el árbol de decisión de `SKILL.md` (objetivo emocional, audiencia, formato, recursos, restricciones) para toda la campaña, y luego para cada pieza individual si varían entre sí.

## Plantilla

```
╔══════════════════════════════════════════════════╗
║  BRIEF CREATIVO — [nombre de campaña]             ║
╠══════════════════════════════════════════════════╣
║  OBJETIVO                                         ║
║  [qué debe lograr la campaña, en una frase]       ║
║                                                    ║
║  AUDIENCIA                                        ║
║  [a quién le habla, qué sabe/no sabe todavía]      ║
║                                                    ║
║  MENSAJE CENTRAL                                  ║
║  [la idea que debe quedar, no el copy literal]    ║
║                                                    ║
║  PIEZAS                                           ║
║  [lista de piezas: formato, plataforma, fecha]    ║
║                                                    ║
║  TONO                                              ║
║  [técnico-cálido, nunca festivo — ver identidad   ║
║  visual de marca]                                  ║
║                                                    ║
║  RESTRICCIONES                                     ║
║  [presupuesto, tiempo, disponibilidad]             ║
╚══════════════════════════════════════════════════╝
```

Cada pieza individual dentro del brief se desarrolla después con `produccion-real.md` o `prompts-ia-imagen-video.md`, según corresponda.
